# 自动验收管线（通用模式）

> 判据全部来自磁盘证据（截图/日志/测试退出码），不采信模型自述。单轮预算按项目定，超时先优化流程再测。

## 流程（四步）

1. **场景重置**：测试前把环境恢复到已知状态（数据/配置/随机种子/临时目录清空），杜绝上一轮残留。
2. **自动执行**：能脚本化的全部脚本化——直进被测状态（跳过导航）、定时执行动作、定时采集证据（截图/导出/日志）。
3. **自动退出**：采集完自动关闭被测系统，证据落盘到固定目录（每轮先清空）。
4. **判定**：对照验收清单逐项核证据；数值类做公式对照；主观类（观感/手感）留给人，单独标注"待用户过目"。
